# Camino Mágico — MIRARIM

Tablero psicoeducativo para mirar, crear e imaginar. Recorre 50 casilleros con preguntas según la edad (4–6, 7–10 y 11–16), de 1 a 6 participantes.

## Uso local

```bash
npm install
npm run dev
```

En **Mis preguntas** se puede escribir una pregunta o pegar varias (una por línea) para agregarlas juntas. También se pueden importar en TXT, CSV o JSON.
